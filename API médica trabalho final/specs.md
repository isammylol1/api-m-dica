# Objetivo

- Desenvolver uma API que receba informações de uma anamnese simplificada e forneça orientações de triagem.

# Requisitos funcionais

- RF01: cadastrar respostas
- RF02: receber sintomas
- RF03: analisar informações
- RF04: identificar sinais de alerta e apresentar orientações.
- RF05: A API deve criar uma anamnese padrão que se repete para todas as pessoas
- RF06: Toda a API deve estar em português
- RF07: A anamnese deve conseguir receber as respostas e analisar as informações
- RF08: A api deve ter cookies e sistema de cadastro para que a pessoa possa consultar suas anamneses
- RF09: Respostas personalizadas para cada pessoa baseado nas respostas da anamnese
- RF10: Em casos onde aparentemente são graves deve indicar um médico próximo com urgência
- RF11: Criar um banco de dados para armazenar as respostas




# Requisitos não funcionais / características

- RNF01: resposta de menos de 5 segundos
- RNF07: Nenhum usuário sem permissão deve acessar o banco de dados e alterar qualquer coisa no código
- RNF03: Carregar o site em menos de 1s
- RNF04: Botões arredondados
- RNF05: Cores frias, maioria cinza e bege
- RNF06: Deve estar 100% em português
